# 喵有回音

在线体验：[喵有回音 · Meow](https://evaqqwww.github.io/Meow/)

适合手机打开的小小猫庙：点猫留下一句话，按住肉垫，和小猫击掌。头顶气泡暂时隐藏。场景采用米色极简布局，只显示寺庙、放大的小猫和互动图形；透明肉垫位于抬起的掌心旁，持续轻抖，按住时的进度圈显示在最上层。

## 使用

1. 点猫后先播放 **250 ms** 轻缩放回弹，再打开输入框。开启“减少动态效果”时直接打开；连续点击去重，切换窗口或隐藏页面取消尚未打开的请求。输入不能为空，最多 **120 个 UTF-16 代码单元**（部分 emoji 占多个），确认后出现肉垫。
2. 连续按住肉垫 **1.8 秒**：先等待 **1 秒**，再用 **0.8 秒** 播放五帧抬爪动画，每 **200 ms** 前进一步。也可用键盘按住空格或 Enter。
3. 成功后内部仍生成随机祝福，排除与输入完全相同的句子，并保留 **1 秒**回应时序；头顶气泡暂时隐藏，成功猫叫照常播放。继续按住时小猫保持末帧；松开后按每帧 **200 ms** 倒放，完整倒放 **0.8 秒**，回应时序结束且倒放完成后可开始下一次互动。
4. 提前松手、移出肉垫、取消触摸或隐藏页面不会触发成功回应。小猫从当前帧倒放，保留输入，倒放完成后可以重试，按住时间不累积。

点猫和成功击掌时，各从 **8 段猫叫**中随机播放一段；提前松手没有成功音。首次点击页面或按 Enter／空格后开始循环播放轻声背景音乐，后台暂停、返回续播，与猫叫独立。音量由设备控制，播放失败不阻塞交互。

输入仅保存在当前页面内存中，刷新或关闭后消失；没有 AI 回复、后端、账户或数据库，也不上传输入。

## 本地运行

需要 **Node.js 22+**，没有第三方依赖，无需安装。

```sh
npm test
npm run dev
```

打开 [本地页面](http://127.0.0.1:4173/) 或 [Pages 子路径预览](http://127.0.0.1:4173/Meow/)。服务只监听本机；指定端口可用 `npm run dev -- --port 4180`。

```sh
npm run build
npm run preview
```

构建只将 `site/` 输出到 `dist/`，为入口脚本、样式和本地模块依赖追加内容版本号，避免旧缓存。不会发布测试或项目配置，也不改动源码和图片。

## GitHub Pages

1. 推送代码到 `main`，在仓库 **Settings → Pages → Source** 选择 **GitHub Actions**。
2. 工作流自动运行测试、构建并发布 `dist/`；也可在 **Actions → Deploy to GitHub Pages → Run workflow** 手动运行。

站点使用相对路径，支持 `/Meow/` 与根路径部署。配置参考：[GitHub Pages 自定义工作流](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。

## 文件与资源

- `site/`：页面、样式、交互与音频模块。
- `site/assets/`：寺庙、肉垫与 `cat-frames/` 中的五张猫动画 PNG，共 **7 张 PNG**。
- `site/assets/audio/`：八段 `meow_01_clean.mp3` 至 `meow_08_clean.mp3`，以及 **58 秒**循环背景音乐 `background-music.mp3`。
- `scripts/`：基于 Node.js 内置模块的构建与预览服务。
- `tests/`：交互、输入、音频和构建测试。
- `.github/workflows/pages.yml`：测试与发布流程。
