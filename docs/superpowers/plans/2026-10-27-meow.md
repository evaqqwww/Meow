# Meow Implementation Plan

> **For agentic workers:** Execute the user's specified flow in this session; use an independent final code review.

**Goal:** Ship the supplied cat/temple mobile interaction to GitHub repository Meow and GitHub Pages.

**Architecture:** Static HTML/CSS/JS with an isolated clock-driven interaction model and relative asset paths. Build copies only public files into dist; Node tests require no packages.

**Tech Stack:** HTML, CSS, ES modules, Node built-ins, GitHub Pages.

**Spec:** docs/superpowers/specs/2026-10-27-meow-design.md

## Global Constraints

- Keep the four original PNGs and copy the user's five new sequence PNGs unchanged into site/assets/cat-frames/; preload all five frames and use the first frame by default. Mobile-first Chinese UI.
- Uninterrupted hold: 3000 ms. Reply: 1000 ms. Keep frame 0 at elapsed 0/1000 ms, then advance every 500 ms to frames 1/2/3/4 at 1500/2000/2500/3000 ms; forward playback lasts 2000 ms after the initial 1000 ms delay.
- Keep the cat at frame 4 while the paw remains held, even after the reply disappears. Release reverses from the current frame every 500 ms to frame 0: a full reverse takes 2000 ms, a partial reverse takes the current frame index multiplied by 500 ms.
- An interrupted hold never produces a blessing; reset hold progress, complete reverse playback, preserve the entered input, then allow a fresh attempt. A successful interaction returns to idle only after release, reverse completion and the 1000 ms reply period. Do not accept a new hold during reverse playback.
- Speech displays a random preset blessing, excluding an exact match with the entered message; input stays in browser memory only.
- Relative paths must work at /Meow/.

## Review Focus

- Interrupted and multi-pointer presses must not complete a hold.
- Background tabs and lost capture must reset in-progress holds.
- Empty/long/special text must remain safe and readable.
- Repeated interactions and editing must not leave stale UI or timers.
- Mobile safe areas, keyboard and short screens must remain usable.
